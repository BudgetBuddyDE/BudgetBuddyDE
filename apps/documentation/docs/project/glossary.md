| Term              | Meaning                                               |
| ----------------- | ----------------------------------------------------- |
| Owner             | Authenticated user who owns a record                  |
| Transaction       | Single income or expense                              |
| Recurring payment | Regularly scheduled income or expense                 |
| Payment method    | Payment source such as an account, card, or cash      |
| API key           | Secret for non-interactive API clients                |
| MCP               | Model Context Protocol for tool and data integrations |
| Workspace         | npm project within the monorepo                       |
| `TResult`         | Tuple convention for success or error                 |
| Drizzle           | ORM and migration tool for PostgreSQL                 |
