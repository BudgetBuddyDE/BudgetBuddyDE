Analytics visualize income, expenses, categories, and budget allocation. Filters from the tables can be used to narrow down time periods or payment sources.

Insights are intended to derive useful guidance from existing financial data. Depending on the version, this feature may still be in development. Treat its statements as guidance, not financial advice.
