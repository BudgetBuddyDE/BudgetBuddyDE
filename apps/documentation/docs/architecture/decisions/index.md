Architecture decisions are recorded as short ADRs (Architecture Decision Records). A decision should remain understandable even if the implementation changes later.

## Template

```markdown
# ADR-XXX: Title

## Status

Proposed | Accepted | Superseded | Deprecated

## Context

What problem or constraint exists?

## Decision

Which solution is used?

## Consequences

What benefits, costs, and risks result?
```

Store new decisions under `apps/documentation/docs/architecture/decisions/` and link them from the architecture overview.
