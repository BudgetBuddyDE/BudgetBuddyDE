A transaction describes a single income or expense. Typical fields include amount, date, description, category, and payment method.

## Recommended Workflow

1. Create a transaction.
2. Select income or expense.
3. Add a category and payment method.
4. Check the date and amount.
5. Save it and check its effect on budgets and analytics.

The table view supports filtering by date range, execution day, category, and payment method. Active filters are reflected in the URL and can be shared.

## Data Quality

Use consistent categories and payment methods. Later changes to a transaction can change historical analytics and budget progress.
