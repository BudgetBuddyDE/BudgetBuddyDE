| Command                  | Purpose                                   |
| ------------------------ | ----------------------------------------- |
| `npm install`            | Install root dependencies                 |
| `npm run dev`            | Start all development tasks through Turbo |
| `npm run dev-services`   | Start services                            |
| `npm run build-packages` | Build packages                            |
| `npm run build`          | Build the entire monorepo                 |
| `npm run format:check`   | Check formatting                          |
| `npm run lint:check`     | Check linting                             |
| `npm run typecheck`      | Check TypeScript                          |
| `npm test`               | Run tests                                 |
| `npm run check`          | Run workspace checks                      |
| `docker compose up -d`   | Start local infrastructure                |

Database commands are described in [Database development](../development/database.md).
