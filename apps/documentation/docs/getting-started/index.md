Choose the path that matches your goal:

- **Use the application:** Read the [user guide](../user-guide/index.md).
- **Develop locally:** Follow the [development setup](development.md).
- **Run your own instance:** Start with [self-hosting](../administration/index.md).
- **Use the API:** See the [API reference](../reference/index.md).

## Prerequisites

Local development requires Node.js 22 or later, npm 11.x, Git, and Docker. The full installation is described in [Set up the development environment](development.md).
