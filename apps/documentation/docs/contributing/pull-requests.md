---
title: Pull Requests
description: Present changes clearly and verifiably for review.
icon: lucide/git-merge
---

A pull request should include:

- Problem and goal of the change
- Affected apps, services, or packages
- Relevant architecture or database impact
- Notes about migrations and configuration changes
- Test and check commands with their results
- Screenshots or short videos for UI changes
- Open questions or known limitations

Keep pull requests small enough for reviewers to fully understand the behavior and risks.
