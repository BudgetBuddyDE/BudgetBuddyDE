Choose the path that matches your goal:

- **Use the application:** Read the [user guide](/user-guide).
- **Develop locally:** Follow the [development setup](/getting-started/development).
- **Run your own instance:** Start with [self-hosting](/administration).
- **Use the API:** See the [API reference](/reference).

## Prerequisites

Local development requires Node.js 24 or later for the documentation workspace, npm 11.x, Git, and Docker. The full installation is described in [Set up the development environment](/getting-started/development).
