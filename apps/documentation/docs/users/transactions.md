Transactions are the base of everything BudgetBuddy calculates: dashboards, budgets, and insights are built from them.

## Record a transaction

Open **Transactions** and create a new entry with the following fields:

| Field          | Description                                                                       |
| -------------- | --------------------------------------------------------------------------------- |
| Date           | When the payment was or will be processed. Dates in the future count as upcoming. |
| Receiver       | Who received or sent the money.                                                   |
| Amount         | See the sign convention below.                                                    |
| Category       | Required. See [Categories](/users/categories).                                    |
| Payment method | Required. See [Payment methods](/users/payment-methods).                          |
| Information    | Optional free-text note.                                                          |

### Sign convention

- **Positive amounts** are income (money received).
- **Negative amounts** are expenses (money spent).

For example, a salary of 2,500 is entered as `2500`, a grocery bill of 42.50 as `-42.50`.

## Edit and delete

Open a transaction to change any field or remove it. Transactions in the future can still be edited; they become part of the actuals once their date has passed.

## Filter and search

The transaction list offers a search field and filters, for example by date range, category, or payment method. Use them to find entries quickly; filters can be combined. Rows can be selected for batch actions where offered.

## Attachments

Receipts and other images can be attached to a transaction. See [Attachments](/users/attachments).
