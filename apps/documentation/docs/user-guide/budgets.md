title: Budgets
description: Set and monitor financial goals for categories.
icon: lucide/target
---

Budgets assign a target amount to a category and a time period. Progress is calculated from the associated transactions.

## Usage

- Select a category and time period.
- Set the target amount.
- Compare spending with the remaining amount.
- Adjust the budget when your plan changes.

Budgets are planning values and do not replace accounting or tax advice.
