## Before You Start

- Search for existing issues and pull requests.
- Discuss larger changes in an issue first where possible.
- Consider the data model, API contracts, and owner isolation.
- Change only what is necessary.

## For Every Contribution

- Add tests for new or changed behavior.
- Update documentation and `.env.example` when behavior or configuration changes.
- Run formatting, linting, the type check, and the build.
- Do not commit secrets, generated artifacts, or workspace-specific lockfiles.
